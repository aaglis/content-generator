# Implementation Status — Viral Content Factory

Este arquivo é o índice root das implementações planejadas.

Use este arquivo para acompanhar o que já foi implementado, o que está pendente e o que mudou.

## Status permitidos

```text
planned      # planejado, ainda não implementado
in_progress  # implementação em andamento
partial      # parcialmente implementado
implemented  # concluído conforme plano
blocked      # bloqueado por decisão, dependência ou erro
changed      # substituído por plano posterior
```

## Como usar

1. Escolha a primeira etapa com status `planned`.
2. Leia o arquivo `.md` correspondente.
3. Implemente apenas o escopo daquela etapa.
4. Atualize este README ao terminar.
5. Se a arquitetura mudar, crie um novo arquivo numerado no diretório `implementations/` e marque a etapa antiga como `changed` se necessário.
